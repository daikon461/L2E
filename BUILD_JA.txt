L2H Armor Set Addon v1.7.0 - ビルド手順

必要環境:
- Java 21
- Gradle 8.10.2（またはGitHub Actions）
- Minecraft 1.21.1 / NeoForge 21.1.x

推奨: GitHubへこのフォルダをアップロードすると、.github/workflows/build.yml が自動ビルドします。
Actions -> Build L2H Armor Set Addon -> Artifacts からJARを取得できます。

ローカル:
  gradle clean build
完成JAR:
  build/libs/armorsets-1.7.0.jar
