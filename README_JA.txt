L2H Armor Set Addon v1.3.0 (開発版)
Minecraft 1.21.1 / NeoForge

対象:
- L_Ender's Cataclysm: 物理系 2セット
- Gobber: 物理系 4セット（通常 / Nether / End / Dragon）
- Iron's Spells 'n Spellbooks: 魔法系 12セット
- Hazennstuff: 魔法系 73セット
- Cataclysm Spellbooks: 魔法系 6セット
- Discerning the Eldritch: 魔法系 2セット
- Minecraft Vanilla: 物理系 6セット（革 / 金 / チェーン / 鉄 / ダイヤモンド / ネザライト）
合計: 105セット

仕様:
- バニラ6セットを控えめに再調整。Mod防具への更新価値を維持
- バニラ4部位には小さな専用フルセット特性を追加（機動/攻撃速度/防御など）
- 2 / 3 / 4部位で累積セットボーナス
- Mod防具はL2Hostility導入環境を想定した高めの数値。バニラのみ意図的に控えめ
- Cataclysm / Gobber は攻撃力・体力・防御・防具強度・移動速度・KB耐性
- 魔法4Modは魔法威力・学派威力・最大マナ・マナ回復・詠唱短縮・CT短縮・魔法耐性・体力
- 装備ツールチップへ日本語でセット効果を表示
- Gobber特殊IDを明示登録し、Nether / End / Dragonを別セットとして正しく判定

注意:
これはv1.3.0のソースプロジェクトです。ビルド前にNeoForge/依存Mod環境でコンパイル確認してください。
次段階ではMod側99セットの4部位パッシブを、装備テーマと学派ごとに追加予定です。

[v1.4.0]
- Mod側99セットにフルセット特性レイヤーを追加。
- Cataclysm/Gobberは専用の物理系最終ボーナスを実装。
- Iron's Spells系は学派別に炎/氷/雷/血/聖/エンダー等の最終補正を実装。
- Hazennstuffは装備名・学派・Battlemage/Knight/Hunter/Ruler/Ascended等の系列から個別特性を生成。
- Cataclysm Spellbooks / Discerning the Eldritchにも専用フルセット説明と魔法補正を追加。
- バニラ6セットはv1.3.0の控えめなバランスを維持。

[v1.5.0]
・Mod防具の4部位セットに戦闘中の発動能力を追加。
・攻撃命中: 物理セットは短時間の攻撃強化、魔法セットは学派別の戦闘バフ。
・被弾: 物理セットは短時間の耐性、魔法セットは吸収シールド。
・撃破: 体力回復。魔法セットは追加で吸収シールド。
・瀕死(HP25%以下): 緊急防御/再生。魔法セットは追加シールド。
・各能力には個別クールダウンあり。バニラ防具は従来通り控えめで、これらの強力な発動能力は付与しない。

[v1.6.0]
- 4/4フルセット専用の戦闘能力を主要セットへ追加。
- Ignitium / Cursium / Gobber Nether・End・Dragon を専用化。
- Iron's Spells主要セットを学派・役割別に専用化。
- Cataclysm Spellbooks / Discerning the Eldritch主要セットを専用化。
- 専用能力発動時に日本語アクションバー、パーティクル、効果音を表示。
- 専用化されていないMod防具はv1.5系の汎用戦闘能力へフォールバック。
- バニラ防具には強力な戦闘発動能力を追加しない。
